  <project_name>Service Business Website Template</project_name>

  <overview>
    A production-ready, professional website template designed specifically for service-based businesses such as plumbers, HVAC technicians, electricians, roofers, landscapers, cleaners, pest control, handymen, pool services, and garage door repair companies. Built with Astro 5.x for static site generation, this template emphasizes trust, reliability, and professionalism with an industrial utility aesthetic. The design philosophy centers on &quot;the reliable guy in the neighborhood&quot; - solid, no-nonsense, and competent rather than flashy or trendy. Key goals include lightning-fast performance (Lighthouse 95+), comprehensive SEO optimization with LocalBusiness schema, WCAG 2.1 AA accessibility compliance, and a mobile-first responsive design. The template features a prominent phone number and &quot;service area&quot; feel that immediately communicates &quot;we come to you.&quot;
  </overview>

  <development_guidelines>
    <guideline>Follow BEM (Block Element Modifier) naming convention for all CSS classes</guideline>
    <guideline>Use CSS custom properties from variables.css for all styling values - never hardcode colors, spacing, or typography</guideline>
    <guideline>Maintain mobile-first responsive design with progressive enhancement</guideline>
    <guideline>Ensure all interactive elements have minimum 44x44px touch targets</guideline>
    <guideline>Include proper ARIA attributes and labels for accessibility</guideline>
    <guideline>Support prefers-reduced-motion media query for all animations</guideline>
    <guideline>Use semantic HTML5 elements (header, main, section, article, footer)</guideline>
    <guideline>Maintain single H1 per page for SEO</guideline>
    <guideline>Provide meta descriptions unique per page</guideline>
    <guideline>Include JSON-LD structured data for LocalBusiness schema</guideline>
    <guideline>Test with Lighthouse for 95+ performance score</guideline>
    <guideline>Ensure 4.5:1 minimum color contrast ratio for body text (WCAG AA)</guideline>
    <guideline>Use TypeScript for type-safe component props</guideline>
    <guideline>Document components with JSDoc-style comments including @example usage</guideline>
    <guideline>Follow Astro&apos;s Islands architecture - minimal client-side JavaScript</guideline>
    <guideline>Use Astro&apos;s built-in image optimization for all images</guideline>
    <guideline>Implement keyboard navigation for all interactive components</guideline>
    <guideline>Include focus-visible styles for keyboard users</guideline>
    <guideline>Support print styles for important content</guideline>
    <guideline>Test in high contrast mode for accessibility</guideline>
  </development_guidelines>
